# 确定性的旧版在线状态传输探针

Status: implemented
Translation: current

[English](2026-10-14-presence-hypothesis-harness.md)

## 摘要

此诊断工具检查同键替换是否会阻止机器心跳发送，以及错误响应正文读取是否会超出已安装传输的请求期限。
工具从明确提供且可信的编译产物中提取方法，使用合成队列项、确认、响应和时钟执行实验。
对照分别取消替换、保留队列位置、结束正文读取或保留正文期限。
结果只证明该产物在给定调度下的机制，不能证明生产故障原因或新版 SDK 的行为。

## 运行与职责

在仓库根目录执行：

```sh
node scripts/probe-presence-hypotheses.mjs --bundle /path/to/trusted/cli/dist/index.js
```

命令以 JSON 输出产物 SHA-256、测量数据和复现或证伪结论，无需安装依赖。
它不会导入完整产物、读取凭据或对话、访问服务、使用真实计时器或启动应用。
提取的方法在 VM 中执行；VM 不是不可信代码的安全边界。
提取依赖已知的旧版编译布局，不支持的产物会明确失败。

队列确认由实验显式调度。慢写入调度在发送之间刷新机器键，同时两个会话键持续参与。
保留位置的变体是敏感性对照，不是产品修复建议。
正文实验分别控制响应头和正文完成，使用合成时钟推进期限，不根据实际耗时判断。
观察结束后会完成所有受控正文 Promise。

## 解释

实验区分捕获的队列屏障与后续独立写入，也区分逻辑待处理数量和物理有效队列项。
期限实验只检查 SDK 自己拥有的计时器，不断言底层传输不存在其他超时。
有限正文和成功响应对照必须通过。不支持的布局或失效的对照会失败；
支持的实现如果不出现假设机制，则报告该情景下的证伪。

本实验涉及[CLI 在线状态](../../../docs/cli-lib-loro-presence.md)的传输预算，不改变应用生命周期所有权。
原生 Effect 传输接口不同，需要独立适配器；本工具不声称测试该接口。
验证结论仅适用于输出中标识的外部产物。

## 验证

[结果 JSON](../../../../scripts/presence-hypothesis-results.json)仅包含合成测量值和检查产物的 SHA-256。

在检查的旧版产物上，慢队列完成 100 次发送，却没有机器发送；物理有效项只有三个，捕获的屏障仍未完成。
取消心跳替换后屏障完成，保留位置对照发送了 33 次机器更新。
停滞的 502 正文读取没有剩余 SDK 请求计时器，而有限正文、204 和正文期限对照均完成。
语法和无效输入检查通过。根验证因缺少 Corepack 和依赖而受阻；
文档与公开边界检查报告已有的断链和无法解析的 ACP 工作区。
不声称已完成门禁提交或生产修复。
